# Банная площадка

Сайт-каталог: бани на дровах, банщики и пармастера, банные чаны, школы банщиков.
Сделан на Next.js. Каждая правка в ветке `main` автоматически публикуется на Vercel.

## Где что лежит

| Что | Где |
|---|---|
| Название сайта, меню, адрес | `src/lib/site.ts` |
| Бани | `src/data/venues.ts` |
| Банщики | `src/data/masters.ts` |
| Школы | `src/data/schools.ts` |
| Производители чанов, статьи, вопросы | `src/data/tubs.ts` |
| Шапка, подвал, карточки | `src/components/site/parts.tsx` |
| Страницы | `src/app/…` |

Запись с `demo: true` это образец карточки. Образцы не попадают в карту сайта и закрыты от поисковиков.

## Разделы и адреса

- `/` главная, вход в четыре раздела
- `/bani-na-drovah`, подборки `/s-chanom` и `/s-basseynom`, страница бани
- `/banshchiki`, анкета мастера
- `/bannye-chany`, статьи и страницы производителей
- `/shkoly-banshchikov`, страница школы
- `/o-proekte`, `/dobavit`, `/politika-konfidentsialnosti`

## Индексация

Пока сайт тестовый, он закрыт от поисковиков. Чтобы открыть, нужно задать переменные окружения
`NEXT_PUBLIC_SITE_INDEXABLE=true` и `NEXT_PUBLIC_SITE_URL=https://боевой-домен`.

## Запуск у себя

```bash
npm install
npm run dev
```
